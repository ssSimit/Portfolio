Cliffside Racing

Cliffside Racing is a physics-based racing game focused on momentum, suspension balance, and precision control across steep cliff tracks. The project was designed to deliver an arcade-style experience while still feeling grounded in responsive vehicle physics.

Play on Y8

About the Project

Cliffside Racing was built as a fast and skill-driven driving experience where players navigate uneven terrain, sharp slopes, and narrow cliffside paths. The gameplay challenge comes from controlling acceleration, braking, and tilt while maintaining traction on unpredictable surfaces. Rather than relying only on top speed, the game rewards consistency, timing, and stable driving under pressure. The core goal of the project was to create satisfying car movement that feels both fun and readable for a broad player base. Special focus was given to handling responsiveness, camera stability, and level flow so the game remains engaging from the first run while still offering room for mastery through repeated play.

Tools & Techniques

  • Unity (2D/Physics-based gameplay)
  • Sprite Shape system for building curved terrain and natural landscapes
  • Wheel Joint 2D for implementing suspension and wheel rotation mechanics
  • Endless terrain generation pipeline for continuous race tracks
  • Y8 SDK integration for platform features and ad support
